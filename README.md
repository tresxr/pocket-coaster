# Pocket Coaster

A tiny nostalgic roller-coaster game rendered entirely with HTML Canvas and the Web Audio API.

## Controls
- Lean: Left/Right arrows or A/D
- Boost: Space
- Mobile: on-screen controls

No build step or external assets are required.

## Aureole — native Android 3D world

The independent Godot application lives in [`aureole/`](aureole/README.md). Its Android workflow produces a signed ARM64 debug APK and a native rendered screenshot as a downloadable Actions artifact. The original browser game above remains available in `index.html`.
